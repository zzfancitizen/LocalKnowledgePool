# 系统交付角色 (System-Delivered Roles)

> 位于 root `/`。**full** = get/watch/update/patch/create/delete;**read** = get/watch;**update** = update/patch。聚合 label 形如 `<group>/role-name-for-aggregation: <role>`。

## Accounts 组

| 角色 | 说明 |
|------|------|
| `accounts.admin`(聚合角色) | 对某 `Organization`(不含创建)或 `Folder` 及其 `ResourceGroup`/`Role`/`Binding`/`TechnicalClient`/`ServiceInstance`/`Secret`/`ServicePublishConfiguration` **full**;对 `Eligibility` **read** |
| `accounts.viewer`(聚合) | 上述 **read** |
| `accounts.resourcegroup-admin`/`-viewer` | 特定 RG 的 full/read |
| `accounts.hierarchy-admin`/`-viewer` | 对 `Organization` **read/update**,对 `Folder`/`ResourceGroup` 层级 **full**(viewer 为对应 read) |
| `accounts.authorization-admin`/`-viewer` | 对 `Role`、`Binding` 的 full/read |
| `accounts.resourcegroup-hierarchy-admin`/`-viewer` | 按 Binding 所在层授予相应 RG full/read + 上层 read |

## Commercial Integration 组

| 角色 | 说明 |
|------|------|
| `accounts.commercial.admin`(聚合到 admin) | 对组织商业化信息(如 `Eligibility`)与 `PathBinding` full |
| `accounts.commercial.viewer`(聚合到 viewer) | read |

## Services 组

| 角色 | 说明 |
|------|------|
| `services.serviceprovider` / `services.serviceprovider.viewer` | 对 `ManagedService`/`ServicePublishConfiguration`/`ServiceMetadata`/`RTD`/`ResourceTypeManagement`/`AllowNested`/`ValidatingWebhookConfiguration`/`Localization`/`APIExtension`/`TechnicalClient`/`Secret`/`Alias`/`Lease` full/read(viewer 不含 Secret) |
| `services.admin`（聚合到 accounts.admin/resourcegroup-admin）/ `services.viewer`（聚合到 accounts.viewer/resourcegroup-viewer） | 对 `ManagedService` 中指定的 RTD 的 full/read(admin 含 Secret,viewer 不含) |

> 提示:`services.serviceprovider` 是使用 [[入门-快速向导创建 App|Quick-Start Wizard]] 的必要角色。

## General 组

- `secrets.admin`/`.viewer`、`technicalclients.admin`/`.viewer`
- `policies.identity-admin`/`-viewer`:`Binding`/`RuleRestriction`/`Role`/`custompolicies.resource.api.sap` 组
- `policies.hierarchy-admin`/`-viewer`:`PathBinding`/hierarchy `RuleRestriction`/`hierarchy.custompolicies.resource.api.sap` 组

## 组织管理员

自动绑到 `accounts.admin`(对组织层级所有资源 full),可继续向他人授权、并授予他人创建 role/binding 的能力。
