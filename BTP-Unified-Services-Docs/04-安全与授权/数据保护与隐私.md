# 数据保护与隐私

> [!info]
> Unified Services 的数据保护与隐私要点。

## 数据存储与加密

- 所有资源与数据存于 **AWS S3**(Object Store,AWS eu-central 区域)。
- 用 **AWS KMS (SSE-KMS)** + AWS 托管密钥加密。

## 数据访问

- 数据由已认证/授权 client(证书 + 命名用户)增删改;访问级别由 client 负责维护。
- 可经 **REST API、`uctl` CLI、Unified Services Workspace** 删除。

## 个人数据

- **仅 `Binding` 存用户 email**(用于权限分配)。
- `Binding` 变更经 **BTP Audit Log service** 审计。
- 不收集敏感个人数据。

> [!warning] 提醒
> - RTD schema **不得含机密/个人数据**(如需则请求排除 SAP IT 复制)。见 [[系统资源 (TechnicalClient-Secret-RTD)]]。
> - 计量 dimension **不得含个人数据**。见 [[计量资源]]。
> - 供应侧数据保留 30 天;终止 1 周宽限后触发级联清理(GDPR)。见 [[Unified Provisioning 供应#Data Retention 隐私]]。
