# 入门:应用运营模式 (App Operational Modes)

> [!important] INTG-04R1 产品标准
> SAP 产品应以 **SAP-managed** 全自动方式交付,无需客户手动介入/设置。
> **唯一例外**:提供 BTP 平台扩展能力的 BTP PaaS 应用(customer-managed)。

## 1. SAP-Managed(用于 SaaS 应用)

- SaaS 应用:客户**不感知**运行平台,可部署在 SAP BTP 或任何平台。
- 客户自助 provision,拿到一个**已完全配置、完全可用**的 SaaS URL,无额外手动前置步骤。
- 用 BTP 租户模型的 SAP app,在 SAP 自有 global account 里管理客户租户(subaccount)。
- 后续配置/管理用官方 SAP 管理工具(SaaS 管理 UI、SCI 管理等)。

## 2. Customer-Managed(用于 SAP BTP PaaS 应用)

- PaaS 应用:紧耦合 SAP BTP 平台,客户**完全感知** BTP 并掌控某些方面(entitlement 分配、subscription 等)。
- 购买后,合同生效日 entitlement 授予客户 BTP global account,客户经 BTP cockpit 自助访问。
- 客户在自己的 subaccount 管理应用,完全掌控运营(账户设置、区域、配额、连接、destination、安全、租户等)。
