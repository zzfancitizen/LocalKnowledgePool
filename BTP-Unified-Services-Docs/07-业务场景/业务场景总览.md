# 业务场景总览 (Business Use Cases)

> [!abstract]
> 所有场景的共同点:Unified Services 作为 **central control plane**,通过单一接口 [[Unified Service Manager 与 ManagedService|ManagedService]] 承接繁重的跨领域集成,让 app provider 只专注业务。

## Commit to Consume (C2C) — 商业化

- **场景**:SAP 对"按用量付费(pay-per-use)"SaaS 需求的答案。客户预先做资金承诺(commitment),按实际月度用量逐步消耗。
- 提供统一体验:SAP for Me 单一列表、bundled solutions、单合同/单订购、self-service 激活、单一账单。
- 例子:**Industry Cloud Enterprise Agreement (ICEA)**(C2C 先行者)、**One Fund**(公有云客户,单 SKU/合同买 credits)。
- 核心能力 **Commercial Mapping**:把 LoB local tenant 映射到客户 CRM tenant,provider 继续用自己的 tenant ID,零中断。全流程集成 SAP for Me、SAP CRM、Billing。

## Billing and Reporting 计费与报告

- **Billing**:仅消费制(C2C、CPEA)。app provider 向 **CM (Convergent Mediation)** 报用量,**CC (Convergent Charging)** 按月计费(合称 **CM/CC**)。[[Unified Metering 计量]]负责交付用量数据。
- **Reporting (Functional Metering)**:用于分析、cross-charging、license 合规。报告系统:**HAUM**(含 SAP Usage Analyzer)、**Cloud Reporting**、**IE Data Lake Platform**。
- **Usage Reporting Flow**:应用报用量(含 local tenant ID)→ Unified Metering → 转发 CM/CC 及报告工具 → CM/CC 用 [[Unified Commercial Integration (UCI)|UCI]] 从 UP/CLD 补业务上下文。

## Automated Provisioning and Integration

- **场景**:SAP 从"provision 独立小应用"转向"provision 完整业务解决方案",客户购买后近乎即时 onboarding。
- **区分两层**:tenant provisioning(置备逻辑实例)与 tenant integration(集成多个实例)。
- **核心机制**:desired-state 声明式控制平面 + software-based operators。Provider 可自建 operator 或 **lease** 平台 operator:
  - **SPFI**([[Unified Provisioning 供应|UP]] 提供)— 桥接现有 provisioning 系统 SPC/CIS
  - **SPII**([[Unified Customer Landscape (UCL)|UCL]] 提供)— 实现 tenant mapping
- 业务决策(选哪个 tenant 集成 = business integration)归客户;技术细节(复制凭据 = technical integration)归 SAP/partner 自动完成。

## SCI Security 安全

- **SCI 组成**:IAS(认证)、IPS(身份供应)、IdDS(身份目录 SCIM 2.0)、AMS(授权)。见 [[SCI 身份与安全]]。
- **场景**:让应用/服务认证用户、多租户认证、跨应用 SSO。
- SCI 作为 `ManagedService` 注册;Provider 建 `SCIApplication` 资源。

## 其他场景

- **Global Service Consumption**:把 SAP common/kernel 服务转为全球化消费模型(例:SAP Start、SCI、CBC、Task Center)。
- **Partner Ecosystem**:让 SAP partner(SI/ISV/OEM)复用 provisioning/integration 机制。
