# 嵌入式租户资源

> API group:`services.resource.api.sap/v1`。概念背景见 [[Embedded Tenants 嵌入式租户]]。均须配置为 `ManagedService` 的 provider resource(`associatedWith`)。

| 资源 | 说明 |
|------|------|
| **`EmbeddedTenantsConfiguration`** | 为资源类型建模其**私有**依赖租户 |
| **`EmbeddedTenantGroupConfiguration`** | 定义/管理一组**共享租户** |
| **`TenantGroup`** | mixin(由 Embedded Tenant Manager 管理),持有该组应创建的租户清单 |

## EmbeddedTenantsConfiguration

`spec.resources[*].type` + `tenants[*].{groupVersionType, specTemplate(Go 模板), monitorStatus.enabled, criteria[*].{byPath.{path,recursive} | byCondition.cel, exclude}, mixins[*]}`。

- **specTemplate**(Go 模板 + Sprig):`.SELF`(父 spec)、`.SUBRESOURCES`、函数 `withMixin`/`withFulfillmentData`/`getTenantSupportedRegions`/`toYaml`。
- **criteria**:`byPath` / `byCondition`(CEL)二选一;全含=命中任一即建,全排除=命中任一即跳过,混合时排除优先。
- **FulfillmentData**(仅 v2):`tenantId`/`customer.id` 自动维护,勿在 specTemplate 定义;创建后不更新。

> [!important] 双声明
> Embedded tenant 既要在 `EmbeddedTenantsConfiguration`(技术细节)配,也要在 `ManagedService.providerResources`(元数据,`associatedWith` 指定 host 类型)声明,**缺一则不创建**。

## EmbeddedTenantGroupConfiguration

定义哪些 tenant type 是账户级共享(同业务上下文应用共用)。配置的资源类型须为 `TenantGroup` mixin 宿主。在 Org/Folder 内创建时自动生成专用 ResourceGroup。额外:`onRequest`(按需,用 `TenantDiscoveryRequest`)、`qualifiers[*].key`(区分同 GVT 多实例,目前仅 `region`)。

## 状态

父资源 `status` 两 condition:
- `EmbeddedTenantsProcessed`(ET Manager 处理情况,"2/2 tenants created")
- `MonitoredTenantsReady`(实际 Ready,仅统计启用 `monitorStatus` 的)
