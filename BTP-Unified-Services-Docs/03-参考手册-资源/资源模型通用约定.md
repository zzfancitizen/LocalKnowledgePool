# 资源模型通用约定

> [!info] 说明
> 所有 Unified Services 资源遵循 **Kubernetes 风格声明式模型**。底层平台为 [[Unified Resource Manager (URM)|URM]],服务层为 Unified Services / [[Unified Service Manager 与 ManagedService|USM]],商业化层为 [[Unified Commercial Integration (UCI)|UCI]]。

## 资源结构

```yaml
apiVersion: <group>/<version>
type: <Type>
metadata:
  name: <技术名>
  path: <账户层级路径>
  displayName: <显示名>
  labels: {}
  mixedInto: {}   # mixin 才有
spec: {}
status:
  conditions: []
```

## 字段约束

| 字段 | 约束 |
|------|------|
| `metadata.name` | 技术名,创建后**不可改**;仅小写字母数字 + `-`/`.`,首尾为字母数字 |
| `metadata.path` | 账户层级路径 |
| 全路径(`path` + `/` + `name`) | **≤ 64 字符** |
| `metadata.displayName` | ≤ 100 字符(`spec.displayName` 已弃用) |
| `spec.description` | ≤ 250 字符 |
| 单个资源大小 | ≤ **512 KB**(超出返回 413) |

## status.conditions[*]

| 字段 | 说明 |
|------|------|
| `type` | `Ready` / `Broken` / `OrchestratorReady` / `<ResourceType>Ready` |
| `status` | `True` / `False` / `Unknown` |
| `reason` | UpperCamelCase |
| `message` | 描述 |
| `observedGeneration` | 与 `metadata.generation` 比对判断是否最新版本(spec 每变更 +1) |
| `relatedResource` | 关联资源 |

> **就绪判据**:`type=Ready` 且 `status=True`。

## Mixin(混入)

经 `metadata.mixedInto`(`apiVersion` + `type`)挂到宿主,`name`/`path` 须与宿主一致。

**常见 mixin**:`FulfillmentData`、`TenantData`、`TenantGroup`、`BTPSolution`、`BTPBlueprintData`、`QuotaAssignment`。

## 修改资源的三种操作

- **Update**(全量)
- **JSON Merge Patch**
- **JSON Patch**

`uctl` 用 `update --update-type` 控制;`edit` 是 GET→编辑器→UPDATE。
