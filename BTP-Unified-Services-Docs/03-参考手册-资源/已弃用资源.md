# 已弃用资源

> [!danger] 勿用于新开发
> 以下资源仅为存量项目/特定 stakeholder 支持,**不要用于新开发**。

## Entitlement → 被 Eligibility 取代 ⭐

- API group `hierarchy.policies.resource.api.sap/v1`。
- 语义与 [[商业化集成资源 (Eligibility 等)#Eligibility 资格核心|Eligibility]] 相近(订单/`ServicePublishConfiguration` 生成、组织级、只读、始终 recursive、消费需 `PathBinding`)。
- **关键差异**:删除 Entitlement 时**其 PathBinding 不自动删除**(Eligibility 会级联删)。
- 伴生只读 `QuotaInfo`;字段用 `crmTenantId`/`entitlementId`(`UNI`/contractId/SPC UID/`leadingEntitlementNumber`)/`lastCalculatedOperationType`/`source[*]`(`origin` ∈ CRM/CRM-ContractLineItem/ServiceProvider/EMS)。
