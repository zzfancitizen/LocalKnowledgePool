# 计量资源

> API group:`metering.cloud.sap.com/v1`。概念背景见 [[Unified Metering 计量]]。

## Account

Unified Metering 服务的基础实体,计量 API 与凭据在 metering account 范围暴露。

`spec` 关键字段:
- `additionalDataStreams`(`btp`,供 BTP 用量上报,CPEA 推荐,若声明须单值)
- `identifier`(`unifiedServices` 默认 / `crmTenantId`)
- `billing.measures`(`all` 默认 / `none` / 数组 ≤50)
- `billing.tenantBusinessTypes`(`all` / `none` / TBT 闭合列表 ≤50)

> 仅含**计费用量对象**(匹配声明的 measures + tenantBusinessTypes)才传给计费系统;其余仅进 Functional Metering 管线。

`status` 含 `accountParameters.name` / `.domain`(组装 Metering API 路径)。

## 生成的 Secret

`Account` Ready 后自动生成含以下的 `Secret`:
- `usageIngestionUrl` / `certificate` / `key`(runtime)
- `certUrl` / `retrievalUrl`(management)
- 证书 **3 个月有效**

## 用量 payload schema

`id`(GUID 去重)、`timestamp`(UTC `yyyy-MM-dd'T'HH:mm:ss.SSSZ`)、`consumer.originServiceInstance.id/type`、`consumer.tenantBusinessType`、`measure.id/value`、可选 `billingContext`/`customDimensions`/`gudfContext`。

POST 响应:201 接受 / 400 无效 / 404 未找到 / 413 超 1MB。

> [!warning] dimension 不得含个人数据。
