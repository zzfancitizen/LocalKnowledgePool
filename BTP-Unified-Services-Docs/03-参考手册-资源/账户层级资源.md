# 账户层级资源

> API group:`accounts.resource.api.sap/v1`。概念背景见 [[Accounts 账户模型]]。

层级:`Organization`(根 `/`)→ `Folder`(可嵌套)→ `ResourceGroup`(叶子,资源实例化之处)。

## 资源清单

| 资源 | 说明 | 关键点 |
|------|------|--------|
| **`Organization`** | 多级层级根实体,代表 SAP 客户/伙伴/内容提供方,引用商务合同实体与全部授权产品(entitlements) | 只能建在 `path: /` |
| **`OrganizationBase`** | **内部资源**,代表面向消费者的 `Organization`,含完整明细与状态,防止消费者改内部信息 | `spec.initialAdmins`(email 数组)→授予管理权限。status:`adminRoleBindingName`(绑 `accounts.admin`)、`viewerRoleBindingName`(绑 `accounts.viewer`)、`organizationName` |
| **`Folder`** | 可选,组织/分组资源、定义边界;可嵌套;单一父 | 建于 Organization 或 Folder 下 |
| **`ResourceGroup`** | 逻辑容器,管理共享生命周期的服务与资源;**资源类型只能在此实例化** | 承载 service instance、配额、计费、标签、访问控制作用域 |
| **`AccountMetadata`** | **只读**,提供上下文(标识、租户分离、成本计算);技术名固定 `account-metadata` | 见下 |
| **`AccountTenantGroup`** | 触发创建账户上下文内的一组**共享租户**(如共享 Audit Log 租户) | 清单存于 `TenantGroup` mixin;配置来自 `EmbeddedTenantGroupConfiguration`。status 含 `EmbeddedTenantsProcessed` |

## AccountMetadata 细节

- `spec.accountIdentifier.type` ∈ {`CRM`, `COST_CENTER`, `INTERNAL_ORDER`, `WBS_ELEMENT`} + `id`
- `spec.ownership` ∈ {`SAP`, `Customer`, `Partner`, `Sandbox`, `Demo`}
- 沿层级**向下继承**,遇下游更近者覆盖。
- 工具函数 `GetAccountMetadata(ctx, client, resource)` 取最近上游实例。

## API Extensions(POST,`APIExtensionRequest`/`APIExtensionResponse` 信封)

- **Subdomain Availability API**:校验 BTP subaccount subdomain(`content.subdomain` + 可选 `region`;返回 `status: PASS/FAIL`)。当前限 SAP for Me。
- **Customer Global Accounts API**:按 CRM `customerId` 查 BTP 全局账户;`commercialModels` ∈ {`PPU`(含 BTPEA/CPEA/PAYG), `Subscription`}、`userEmail` 过滤。
