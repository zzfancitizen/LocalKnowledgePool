# 遥测与中央通信服务

## 一、解决方案遥测事件 (Solution Telemetry Events)

**`TelemetryConfiguration`**(provider resource,`spec: {}` 空)经 `ManagedService.providerResources` 关联后,自动向 **OpenTelemetry 后端(octoroute)** 上报生命周期事件。

**Solution 事件**(均 v1.0):
`solution.created`、`solution.processing.started`、`solution.tenants.completed`、`solution.integrations.started`、`solution.integrations.completed`、`solution.completed`、`solution.deleted`。

**Tenant 事件**(每租户,v1.0):
`tenant.created`、`tenant.processing.started`、`tenant.processing.completed`。

触发条件基于 solution `Ready` 条件与 `BTPBlueprintIntegrations` 条件的 `Status`/`Reason`(Processing/Error)。

## 二、中央通信服务 (Central Communication Service, CCS)

**`CCSConfiguration`**(`ccs-leased-operator.ccs.core.sap.com/v1`):租户激活时发**激活邮件**。

- `spec.templateMatchKey`(CCS 中模板的 Match Key)
- `spec.dataTemplate`(Go 模板生成数据负载,可取 `TENANT.spec`/`TENANT.status`、`FULFILLMENT_DATA`、`TENANT_DATA`;自定义函数 `itemFromArrayByMatchingKey`、`toYaml`)
- `recipientsCc` / `recipientsBcc`

> [!note] 触发时机
> **仅在租户首次创建(`CCSTrigger` 生成)时触发一次**;更新 config 或 reconcile 不重发。用 CCS Admin Panel 的 Preview/Test Template 迭代模板。
