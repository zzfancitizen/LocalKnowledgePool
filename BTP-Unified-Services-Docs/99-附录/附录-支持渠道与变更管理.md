# 附录:支持渠道与变更管理

## Getting Support(支持渠道)

- **Teams 频道**(Forum):讨论一切 Unified Services 问题。
- **Bug 首选** SAP JIRA 项目 **SAPBTPCFSBUG**,按组件用对应模板(URM API、Frontend[Workspace/UPC/SAP for Me]、CLI、UCI、UA、USM、UCA、BTP Solution Operator)。
- ServiceNow 组件:URM API=`XX-UNI-RES`;USM/BTP Solution Operator=`XX-UNI-SRVMGR`;UA/UCI/UCA=`XX-UNI-ACT`。
- **UCL** bug → NGPBUG("Central Management Plane" / SNOW `BC-CP-MP`)。
- **Unified Provisioning** SNOW:CLD Operator=`AP-LM-SPC-UP-CI`、Tenant Operator=`AP-LM-SPC-UP-SL`、SPC SPFI=`AP-LM-SPC-UP-SMT`。
- **SCI**:`BC-IAM-IB`(provisioning)/`BC-IAM-IDS`(功能)。
- **Metering** → NGPBUG "Unified Metering" 组件。
- 文档反馈 → atom-docs GitHub issues。

## Change Management(变更管理)

采用**采纳时间线公式**:按 Effort to Adopt(Small/Medium/Large)× Impact/Severity(High/Medium/Low)计算采纳周数,范围 **8–24 周**(如 Small+High=8 周,Large+Low=24 周)。
沟通渠道:Teams 频道(始终)、DL Unified Resource and Service Management Comm(中/高影响)、Unified Services Newsletter(高影响)。

## Troubleshooting and Monitoring

主排障工具是 [[UPC 统一提供方驾驶舱|UPC]]。
- **provisioning 失败**:Solutions/Tenants 页按 CRM ID 过滤,看 `Ready` 状态消息,查 `BTPSolution`/`FulfillmentData` mixin。
- **integration 失败**:暂未在 UPC 支持,需向 UCL 开 Jira。
- 辅助工具:CAD Automation Analytics、Unified Services Resource Visualizer (URV)、Workspace Resource Event Viewer。

## FAQ 关键事实

- 资源 `metadata.name` 上限 63 字符;单个资源 ≤ **512 KB**(超出返回 413)。
- URM 是**最终一致**系统;删除靠 finalizers,可能耗时数小时;卡住按 finalizer 前缀开工单。
- 修改资源三操作:Update(全量)、JSON Merge Patch、JSON Patch。
- 单个 SAP-managed app 也须作为 product suite onboard(suite 可只含 1 个组件)。
- commercial mapping:`tenantProductType` 和 `cldSystemRole` **全局唯一**。

## SAP Support Access to Customer Subaccounts

SAP-managed 应用须用 **SAP CAM (Cloud Access Manager)** 授予 support 人员访问客户 subaccount(onboarding 时一次性)。在 BTP 建 Role Collection "SAP Support Subaccount Admin",配 CAM(强制 2FA=SAPID_CAM_MFA)。事故时经 CAM self-service "Request User" 临时获取(默认有效期 1 天,须客户批准)。
