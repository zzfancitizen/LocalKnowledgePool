# 动机与背景 (IES 战略)

> [!info] 背景
> SAP 的公司战略 **REINVENT** 聚焦 "Product & Architecture、Customer Engagement、Partner & Ecosystem、People"。**Intelligent Enterprise Suite (IES)** 是这一战略的技术承载,而 [[什么是 Unified Services|Unified Services]] 是 IES 的**关键使能者(key enabler)**。

## IES 的主要技术挑战

Unified Services 直接应对以下 IES 核心技术挑战:

### One digital customer experience(统一数字客户体验)
客户当前面对的是碎片化、不一致、低效的多种方式与 SAP 打交道,信息不全或缺失,导致挫败感,也让客户错失改进业务的转型机会。

### One customer engagement workspace(统一客户互动工作台)
从单体架构转向 **Platform Play** —— 提供一组可复用的中心化服务,灵活组合以支撑客户互动的业务能力;通过治理减少能力重叠、优化投资。

### Steering IT Investments with business capabilities(以业务能力驱动 IT 投资)
用业务能力驱动的架构支撑最优决策。业务能力是业务架构的功能构件,定义组织成功执行某项独特业务活动的能力。

### Platform game plan and enablement(平台规划与使能)
从松耦合异构的开发者工具集,转向为开发者提供端到端、安全合规的集成旅程,覆盖 No Code / Low Code / Pro Code 开发框架。

## Unified Services 作为使能者

Unified Services 优化 IES 战略的前三大支柱:**Streamlined face of business、Customer centricity、Business agility**。

| IES 技术挑战 | Unified Services 作为使能者 |
|--------------|------------------------------|
| SAP 的体验挑战(统一数字客户体验/互动工作台) | 跨 SAP 解决方案:注册并消费来自 SAP 与 Partner 的方案。例:Marketplace、Industry Cloud |
| 以业务能力驱动 IT 投资 | One-SAP Bill:RISE with SAP、S/4 Cloud Suite Foundation |
| 平台规划与使能 | Development-environment-as-a-service |
